# Synthetic workbook fixture

`self-authored.xlsx` is technical test data generated by
`backend/tests/xlsx_fixture.py::self_authored_xlsx`. Its two sheets contain only
invented item names and counts; it is not a cultural source.

To regenerate from the repository root:

```bash
uv run --package culturechamp-backend --extra dev python -c 'import sys; from pathlib import Path; sys.path.insert(0, "backend/tests"); from xlsx_fixture import self_authored_xlsx; Path("frontend/e2e/fixtures/self-authored.xlsx").write_bytes(self_authored_xlsx())'
```

The fixture has a vertical merged row key, an interior empty cell and an exact
`North` sheet cell at row 3, column 2. The live browser check uses it to verify
the XLSX path through review, indexing, materials, chat and original download.

`self-authored-pages.pdf` is generated by
`backend/tests/pdf_fixture.py::self_authored_pdf` with two invented ASCII page
sentences. It tests physical PDF page locators and the approved original route;
it is not a cultural source. Regenerate it from the repository root:

```bash
uv run --package culturechamp-backend --extra dev python -c 'import sys; from pathlib import Path; sys.path.insert(0, "backend/tests"); from pdf_fixture import self_authored_pdf; Path("frontend/e2e/fixtures/self-authored-pages.pdf").write_bytes(self_authored_pdf("Synthetic first page blue kites", "Synthetic second page copper discs seven"))'
```
